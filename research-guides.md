faqs:
  - q: "Where do I start with Puerto Rican genealogy research?"
    a: "Start with yourself and work backward. Collect birth certificates, marriage records, and death certificates for your parents and grandparents. Then use FamilySearch's Puerto Rico Civil Registration collection (1885-2001) and Catholic Church Records collection (1645-2021) to push further back. Our Getting Started guide walks through the full process."
  - q: "What records are available for Puerto Rico before 1885?"
    a: "Before civil registration began in 1885, the primary records are Catholic Church registers: baptisms, marriages, and burials. Some parish records date to the 1600s. These are available through FamilySearch's Puerto Rico Catholic Church Records collection (1645-2021). Sacramental records often recorded parents' names, ages, origins, and social status."
  - q: "Do I need to speak Spanish to research Puerto Rican genealogy?"
    a: "You do not need to be fluent, but familiarity with common Spanish genealogical terms is essential. Most historical records are in Spanish. Our free Spanish Genealogical Glossary lists the most common terms you will encounter in civil and church records."
  - q: "Are Puerto Rican genealogy records available online for free?"
    a: "Yes. FamilySearch offers free access to two major collections: Civil Registration 1885-2001 and Catholic Church Records 1645-2021. Many records are digitized and browsable without a paid subscription. Our research guides explain how to navigate both collections."
  - q: "What is the double-surname system in Puerto Rican records?"
    a: "In Puerto Rico, people traditionally carry two surnames: the father's first surname followed by the mother's first maiden surname. For example, Juan Rivera Rodriguez means Rivera is from his father and Rodriguez is from his mother. Women keep their birth surnames after marriage. Knowing both parents' surnames is essential for finding records."
  - q: "How far back can I trace Puerto Rican ancestors?"
    a: "With church records, it is possible to trace some families to the 1600s, though coverage varies by parish and record survival. Civil registration provides reliable coverage from 1885 onward. Slave records (Registros de Esclavos) from 1872 can connect descendants of enslaved people to specific towns and, in some cases, to African origins."
  - q: "What is the 78 municipalities guide?"
    a: "Puerto Rico has 78 municipalities, each with its own civil registry, Catholic parish history, and record start dates. Our Municipality Guide covers all 78 with parish names, civil record start dates, barrios, and direct FamilySearch links — so you know exactly which records to search for your ancestor's town."
  - q: "Are these research guides free?"
    a: "Yes. All guides on this site are free and self-paced. They are written to GPS (Genealogical Proof Standard) principles developed by the Board for Certification of Genealogists."

## Puerto Rican Genealogy Research Guides

Discover your Puerto Rican ancestors with practical guides to historical records, research methods, DNA, and online resources. Spanish-language records, a complex colonial history, and archives in Puerto Rico, Spain, and the United States make this research unique, and these guides are built for that journey.

<script>
(function() {
  var input = document.getElementById('guide-search-input');
  var status = document.getElementById('guide-status');
  var none = document.getElementById('guide-none');
  var cards = document.querySelectorAll('.guide-card');
  var sections = document.querySelectorAll('.guide-section');
  var total = cards.length;

  function norm(s) {
    return (s || '').toLowerCase().normalize('NFD').replace(/[̀-ͯ]/g, '');
  }

  var index = [];
  cards.forEach(function(card) {
    // Words are matched by prefix, so "ai" finds AI Tools but not "military".
    index.push(' ' + norm(card.querySelector('h4').textContent + ' ' +
      card.querySelector('.guide-desc').textContent + ' ' +
      (card.getAttribute('data-keywords') || '')).replace(/[^a-z0-9]+/g, ' '));
  });

  function run() {
    var tokens = norm(input.value).split(/\s+/).filter(Boolean);
    var shown = 0;
    cards.forEach(function(card, i) {
      var ok = tokens.every(function(t) { return index[i].indexOf(' ' + t) !== -1; });
      card.style.display = ok ? '' : 'none';
      if (ok) shown++;
    });
    sections.forEach(function(sec) {
      var any = Array.prototype.some.call(sec.querySelectorAll('.guide-card'), function(c) { return c.style.display !== 'none'; });
      sec.style.display = any ? '' : 'none';
    });
    none.hidden = shown !== 0;
    if (!tokens.length) {
      status.textContent = status.getAttribute('data-all').replace('{total}', total);
    } else {
      status.textContent = status.getAttribute('data-some').replace('{n}', shown).replace('{total}', total) + ' · ';
      var clear = document.createElement('button');
      clear.type = 'button';
      clear.className = 'filter-clear';
      clear.textContent = status.getAttribute('data-clear');
      clear.addEventListener('click', function() { input.value = ''; run(); input.focus(); });
      status.appendChild(clear);
    }
  }

  input.addEventListener('input', run);

  // Tile and anchor clicks must never target a section hidden by a search.
  document.querySelectorAll('.guide-tiles a').forEach(function(a) {
    a.addEventListener('click', function() { if (input.value) { input.value = ''; run(); } });
  });

  // Print with every card detail expanded.
  window.addEventListener('beforeprint', function() {
    document.querySelectorAll('.guide-card details').forEach(function(d) { d.open = true; });
  });

  run();
})();
</script>
