## Lo Que Puede Hacer

Puede utilizar el contenido de este sitio web para los siguientes propósitos sin necesidad de solicitar permiso previo:

- **Investigación genealógica personal:** Puede leer, imprimir y guardar el contenido para su propia investigación de historia familiar.
- **Uso educativo no comercial:** Puede compartir páginas individuales o extractos en un salón de clases, grupo de investigación o sociedad genealógica, siempre que incluya una atribución clara (consulte la Guía de Citas a continuación).
- **Enlazar:** Puede enlazar a cualquier página de este sitio web desde su propio sitio web, blog o redes sociales.

## Lo Que No Puede Hacer

Los siguientes usos están prohibidos sin permiso escrito previo de Sylvia Vargas:

- Reproducir o distribuir cualquier parte sustancial del contenido de este sitio web en cualquier medio (impreso, digital u otro)
- Vender, licenciar o comercializar de cualquier otra forma el contenido de este sitio web
- Crear obras derivadas, adaptaciones o traducciones de los materiales del curso
- Volver a publicar módulos de cursos, guías o folletos en otro sitio web o plataforma
- Eliminar u ocultar cualquier aviso de derechos de autor, marca registrada o atribución
