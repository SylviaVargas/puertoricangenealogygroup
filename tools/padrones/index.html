FamilySearch has digitized hundreds of record groups created by the Gobierno de Puerto Rico: household lists, day-laborer registers, municipal population counts, and enslavement records. Most of them predate civil registration, which did not begin until 1885, so they reach into decades where few other name-bearing sources survive.

These images are not name-indexed. You cannot search them for an ancestor's name. You browse them like a book, which is why knowing the right municipality and year first matters so much. A free FamilySearch account is required to view the images.

New to this kind of record? Start with Padrones and the FamilySearch Image Search, which explains what each record type contains and how to work through an unindexed group efficiently.

Where this list comes from

Every row is an image group published by FamilySearch under the creator Gobierno de Puerto Rico. You can also search that creator directly on FamilySearch:

  • All Gobierno de Puerto Rico image groups
  • Censo Poblacional / Municipal Census

This index is a snapshot, not a live feed. FamilySearch adds image groups continuously, so if a search on their site returns something this table does not list, the record exists and our snapshot is simply older. Please let us know so we can refresh it.
